Privacy policy

Last updated 1 November 2026

The short version

RepoReel is a tool that runs on one person's own computer and publishes to that same person's own social accounts. It has no users other than its operator, no server, and no database anywhere but that computer. It collects no information about anybody.

Who this covers

RepoReel is operated by a single individual for their own channel. There is nothing to sign up for, no account to create, and no way for anyone else to use it. If you are reading this because you saw one of the videos, nothing here collects anything about you: you interacted with a social platform, under that platform's own privacy policy, not with us.

What the software stores, and where

Everything stays on the operator's computer. Nothing is transmitted to us, because there is no "us" to transmit to — no hosted service exists.

WhatWhereWhy
Public information about GitHub repositories A local SQLite file To choose which project to make a video about
Scripts, audio, and rendered videos Local folders They are the work product
API credentials for the operator's own accounts A local .env file, never committed to version control To publish to those accounts
A record of what was published where The same local SQLite file So the same video is not posted twice

Third-party services it talks to

All of these are used by the operator, with the operator's own credentials, for the operator's own content:

  • GitHub — the public API, read-only, to find and read public repositories. No private data is accessed; the token used has no permission scopes at all and exists only to raise the rate limit.
  • Hugging Face — to download the text-to-speech model weights, once.
  • Anthropic — the Claude Code tool, to draft the video script and the captions.
  • HeyGen / HyperFrames — to fetch music, sound effects, images and logos used in the videos, and to render them.
  • YouTube, TikTok and Instagram — to upload videos to the operator's own accounts and to post a first comment on them.

Each of those services handles data under its own privacy policy.

Platform permissions, and what they are not used for

Where RepoReel is granted access to a social account, that access is used only to upload a video to that account and to post a comment on that same video. It is not used to read anyone's content, to follow or message anyone, to collect audience information, or to act on any account other than the operator's own.

Access tokens are stored only in the local .env file. They can be revoked at any time from the platform's own settings, which immediately and permanently ends RepoReel's access.

Other people's work

The videos explain public open-source projects. Each one credits the project's authors, links the repository, and makes clear that it is an independent explainer and not official content from that project. Material used under a licence that requires attribution is credited in the video's pinned comment. If you are the author of a project and want a video about it taken down, the contact address below is enough — no justification required.

Children

The channel publishes technical content for software developers and is not directed at children. No content is marked as made for kids.
