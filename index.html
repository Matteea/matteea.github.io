RepoReel

Short videos that explain open-source projects.

RepoReel finds interesting GitHub repositories and turns each one into a vertical explainer video — a narrated walkthrough of the one idea that makes the project worth knowing about.

How it works

  1. It searches the public GitHub API for repositories that are growing, new, or established and still active.
  2. It reads a repository's own README and file tree, and writes a short script. A human reviews and edits that script before anything else happens.
  3. It records narration, builds the animation, renders a 1080×1920 video, and checks the file is sound.
  4. A human approves the finished cut. Nothing is published without that.
  5. It writes a caption, hashtags and a first comment for each platform, and publishes to the operator's own accounts.

What it is not

  • It is not a service. It runs on one person's computer, for that person's own channel. There are no user accounts and nothing to sign up for.
  • It does not post on behalf of anyone else, and it has no access to anyone else's accounts.
  • The videos are independent explainers. They are not official content from the projects they describe, and every video credits the project's authors and links the repository.

About the videos

Narration is generated with a text-to-speech model using a clone of the channel owner's own recorded voice, and the visuals are generated. Every video carries each platform's AI-generated content label, and the caption says the same in words.

Each video names the repository's author, links the repository, and only states facts taken from the GitHub API or the project's own README.
